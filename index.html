⚙ 外部財務資料設定

要用股票代號自動載入財報與股價，可以連線你的 Cloudflare Worker API 代理；也能直接使用 FMP API Key（僅供個人本機使用，瀏覽器會接觸金鑰）。不設定也可以手動分析任何股票。

部署壓縮檔內的 worker.js，並在 Cloudflare 設定 FMP_API_KEY secret。網址會保存於本機。
直接連線可能遇到瀏覽器 CORS 限制；網站不會把 Key 傳到其他伺服器。
